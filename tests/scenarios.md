# Promptify behavior regressions

Run each case as a fresh skill invocation with the stated metadata. Use the current `skills/promptify/SKILL.md` and only the relevant references. Metadata belongs to the scenario, not the evaluator's own runtime. Save the full actual response and judge observable behavior. Do not execute any drafted task or change a live model configuration.

For every in-scope case: preserve the user's intent and constraints, deliver a standalone normal prompt, use only supplied/verified target information, and avoid inventing facts, tools, paths, commands, or API capabilities. No mode picker, unsolicited model interrogation, or private-chain-of-thought requests. A target line stays outside the copyable prompt and is omitted when requested. Clarification is appropriate only when essential information materially changes the deliverable.
